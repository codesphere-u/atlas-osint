# Source coverage report

_Generated by `scripts/generate_source_coverage.py` from the adapter registry – do not edit by hand._

ATLAS ships **40 source adapters**. Coverage is limited to these sources; ATLAS does not
claim to search the whole internet. Each investigation's report lists which sources were consulted and
what each one returned (ok, no results, skipped, not configured, rate-limited, unavailable, error).

Reliability grades: **A** authoritative primary source · **B** usually reliable (platform about its own
users) · **C** fairly reliable aggregator · **D** not usually reliable (index / crawl) · **E** unknown.

## Details

### Crossref works index (`crossref`)

Publication metadata (DOI, title, venue, year, co-author count) for works listing an author with the searched name. Author ORCID iDs, when deposited, link works to researcher records.

- **Freshness:** daily
- **Restrictions:** Bibliographic metadata only; abstracts and full text are not collected.
- **Terms:** https://www.crossref.org/documentation/retrieve-metadata/rest-api/
- **Fields collected:** `publication_title`, `doi`, `year`, `venue`, `work_type`, `author_position`, `coauthor_count`, `author_orcid`, `candidate_name`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### OpenAlex author index (`openalex_authors`)

Open catalogue of scholarly authors, works and institutional affiliations.

- **Freshness:** updated continuously
- **Restrictions:** CC0 data. Author disambiguation is algorithmic and can be wrong.
- **Terms:** https://openalex.org/about
- **Fields collected:** `candidate_name`, `persistent_id`, `id_scheme`, `affiliations`, `works_count`, `cited_by_count`, `topics`, `description`, `orcid`, `profile_url`, `occupations`, `employers`, `official_website`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### ORCID public registry (`orcid`)

Researcher-maintained persistent identifiers with self-declared affiliations.

- **Freshness:** real-time
- **Restrictions:** Only data the researcher marked public is returned.
- **Terms:** https://info.orcid.org/public-client-terms-of-service/
- **Fields collected:** `candidate_name`, `persistent_id`, `id_scheme`, `affiliations`, `works_count`, `cited_by_count`, `topics`, `description`, `orcid`, `profile_url`, `occupations`, `employers`, `official_website`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### Internet Archive Wayback Machine (CDX API) (`wayback`)

Historical captures of a website: first and most recent archived snapshots.

- **Freshness:** historical
- **Restrictions:** Archived public web content; respect site owners' exclusion requests.
- **Terms:** https://archive.org/about/terms.php
- **Fields collected:** `first_capture`, `last_capture`, `first_capture_url`, `last_capture_url`, `capture_status`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### Have I Been Pwned (breach notification) (`hibp`)

Lists names of publicly disclosed data breaches that included the address. Never returns breached data itself. Requires an API key and documented consent of the address owner.

- **Freshness:** real-time
- **Restrictions:** Acceptable use: only for the protection of the address owner. ATLAS requires documented consent (or self-lookup) before calling this API.
- **Terms:** https://haveibeenpwned.com/API/v3#AcceptableUse
- **Fields collected:** `breach_name`, `breach_domain`, `breach_date`, `data_classes`, `is_verified`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`
- **Credentials:** Purchase an API key at https://haveibeenpwned.com/API/Key

### Public document metadata extractor (`public_document`)

Retrieves a publicly accessible document (respecting robots.txt) and records its content hash, type, size, title and embedded document metadata.

- **Freshness:** real-time
- **Restrictions:** Only publicly reachable documents; robots.txt is honoured; content is hashed, not republished. Copyright remains with the publisher.
- **Terms:** n/a
- **Fields collected:** `content_type`, `size_bytes`, `sha256`, `last_modified`, `doc_title`, `doc_author`, `doc_creator_tool`, `doc_created`, `doc_modified`, `final_url`, `outbound_domains`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### Public DNS (`dns_records`)

Authoritative public DNS records (A, AAAA, MX, NS, TXT, CAA, SOA).

- **Freshness:** real-time (subject to TTLs)
- **Restrictions:** Public DNS data.
- **Terms:** n/a
- **Fields collected:** `record_type`, `values`, `spf`, `dmarc`, `verification_tokens_count`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### Email-security DNS records (`email_security`)

SPF, DMARC, MTA-STS, TLS-RPT, BIMI, DNSSEC and common DKIM selectors. The MTA-STS policy file is fetched only for domains in the authorised scope.

- **Freshness:** real-time (subject to TTLs)
- **Restrictions:** Public DNS data; one public policy-file request within authorised scope.
- **Terms:** n/a
- **Fields collected:** `spf`, `spf_all`, `dmarc`, `dmarc_policy`, `dmarc_pct`, `dmarc_rua`, `mta_sts`, `mta_sts_mode`, `tls_rpt`, `bimi`, `dnssec`, `dkim_selectors_found`, `mail_enabled`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### Lookalike-domain discovery (DNS) (`lookalike_domains`)

Generates typosquat, homoglyph, TLD-swap and keyword permutations of an authorised domain and checks which are registered and mail-capable using DNS only – a brand-protection check.

- **Freshness:** real-time
- **Restrictions:** Only for domains in the authorised scope (your own brand). DNS lookups only; no requests are sent to the lookalike domains' web servers.
- **Terms:** n/a
- **Fields collected:** `lookalike_domain`, `technique`, `a_records`, `mx_records`, `mail_capable`, `candidates_checked`, `registered_count`, `mail_capable_count`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### RDAP domain registration data (IANA bootstrap) (`rdap_domain`)

Registration Data Access Protocol – the ICANN-mandated successor of WHOIS.

- **Freshness:** real-time
- **Restrictions:** Registries redact personal registrant data (GDPR). ATLAS records registrant organisation names only and never personal registrant contact details.
- **Terms:** https://www.icann.org/rdap
- **Fields collected:** `registrar`, `registrar_iana_id`, `created`, `expires`, `updated`, `status`, `nameservers`, `registrant_org`, `dnssec`, `rdap_server`
- **Citation format:** `{display_name}. "{title}". {url}. Retrieved {collected_at}.`

### SSLMate Cert Spotter (CT issuances) (`certspotter`)

Unexpired certificates for a domain and its subdomains from Certificate Transparency logs. Complements crt.sh (independent infrastructure, corroborates subdomains).

- **Freshness:** near real-time
- **Restrictions:** Subdomain names are listed only for domains inside the authorised scope.

Certificates logged in public Certificate Transparency logs (RFC 6962).

- **Freshness:** near real-time
- **Restrictions:** Public CT log data. Subdomain names are listed only for domains inside the investigation's authorised scope.
- **Terms:** https://crt.sh/
- **Fields collected:** `certificate_count`, `issuers`, `first_seen`, `last_seen`, `subdomain`, `subdomain_count`, `first_cert_not_before`, `listing_withheld`
